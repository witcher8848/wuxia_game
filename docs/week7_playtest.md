# 第七周试玩：时辰、日程和人情

本表只收第七周反馈，不必重填以前的战斗／美术表。当前使用源码开发入口，旧第六周冻结包没有本周内容。

## 怎么玩

1. 双击仓库根目录 `Run.command`，新游戏或读取已有探索档。正常结束开篇后，左上角会显示时辰与H提示。
2. 按H查看时辰，E先看等候预览。默认选项是取消；按↓再E才会推进。先试取消，确认人物和时间不变，再实际等候一次。
3. 在县城寻找摊主，靠近面向他按E，再H查看人情。帮忙会先说明1时段代价；确认后，关系／乡里声望变化，摊主可能去区域内另一处忙活。重新靠近交谈，听听与之前的差异。
4. 也到码头找船夫；旧调查／质证和前往罪坟的主线仍保留，人情不是获得主线证据的门槛。
5. 按J打开命卷，Q／R切到人物页。F5或暂停菜单手动存档，退出游戏后重新打开并读档，查看时辰、人物位置和关系是否一致。

普通走路、跨图、阅读和交谈不耗时。不想花时就取消；每天每NPC只能帮忙一次。没有自动保存，面板内不能F5；请退出面板后保存。不要为了测试覆盖想保留的旧档，可另用一个手动槽。

日程目前为每日8技术槽循环，不是正式三日八剧情时段或实时倒计时；不因等候造成封城／主线失败。摊主和船夫始终在原来的县城／码头，只换站位。其他NPC和场景仍灰盒。最终美术、分支剧情、Windows与实体手柄不在本轮验收中。
