# 第四周闭环试玩记录

状态：待实际试玩反馈。第三周已给过的技能栏意见已归档，不要求重填；本表只看新增调查与剧情战斗闭环。

## 如何开始

- 本机候选包：双击包目录内 `Play-on-Mac.command`，依赖仓库已安装的固定 Godot；不是独立 Mac App。候选使用独立存档目录，不覆盖平日开发档。
- 源码：双击仓库 `Run.command`；不要用 `Battle.command`，那是旧的独立战斗实验场。
- WASD／方向键移动，Shift奔跑；靠近并面向文书／船夫按E。对白↑↓选项，E确认，Esc离开。J打开命卷，Q／R切页。
- 战斗用E预览后再次确认，Esc逐级返回，F查看敌人，R确认重试。胜利后选择结算才推进一时段；失败、重试、退出不扣剧情时段。
- 战后关闭对话，F5快速存档；或Esc→手动存档。彻底关闭窗口后重新启动，在标题菜单选读档。

## 两次游玩（不看下面折叠提示也可以）

## 原型边界

本周只到解救老妇后出现迁坟旧账线索，不开放后续地区／正式三日剧情／恋爱内容。老妇在叙事中先行撤离，战斗目标是击退追兵，**不是已经实现保护可受攻击NPC或护送AI**。战斗复用第三周固定属性，胜利写回任务、事实、信任与时段；暂不把本局气血写到探索占位属性。没有战中存档或完整回溯。美术和数值按既定决定后续细化。

自动测试、脚本控制的实际战斗、截图和导出不能代替上述人工体验。15～20分钟是待验证目标，不是已有测试结果。Windows真机、实体手柄和独立备份仍按各自记录跟踪。
