- 参与者：haojie；平台原填 `mac`；时长原填 `7`，按约 7 分钟记录，未补造起止时间、窗口尺寸或具体候选指纹。

## 4. 新版针对性复测

从项目根目录双击 `Run.command`，确认新版版本后进入小镇。只需先测改动的体验，未变部分沿用原记录的证据范围：

1. 同一段道路先走再按 Shift 冲刺：步速是否合适？冲刺差异是否足够明显？尘点是否干扰阅读／识路？转角有无新增卡住。
2. 按 F5 快存；在暂停菜单选手动槽 1 保存；移动到另一处再按 F5。分别读手动槽 1 和快速档，是否能分辨且回到各自位置。
3. 对已有手动槽发起覆盖，先取消一次，再确认一次；取消应保留旧进度。另试一个空槽，观察提示是否清楚。
4. 退出重开，在标题通过读档列表选档；按 Esc 返回应回到上一层，不误退出菜单、不让背景角色移动。
5. 记录实际复测时长、日期及新版版本。原 7 分钟加本次体验可以分别记录，不伪造单次十分钟；是否足以接受本周操作基线由本人确认。
