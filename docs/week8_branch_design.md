# 第八周分支草案：《一刻两头》

2026-10-16，建议稿，待共同确认。基线`e3e7ce4`。这是第八周内容／接口设计，不是已经落地的任务或对上位剧情的批准变更。排期见[Day50～56](../武侠RPG_第八周每日任务.md)。

## 1. 玩家为什么要做

玩家不是为收集名册而跑地图：父亲已死、自己被通缉，女囚父亲的遗骨又面临迁坟；守墓老妇与埋尸簿能把“父亲独自伪籍”的指控变成可追查的共同旧案。眼前目标仍是**先找到老妇，保住人和能复核的线索**。

外部压力来自同一轮清籍：县衙查抄父亲住所，也传问渡口相关人员。主角无法同时亲自保全两处完整机会，但不会因为读得慢、问错话或走错路突然失败。

不新增幕后全知反派，不改变已确认的县衙／清籍官／承岳门／雁回门地方冲突；本周只透过既有言行呈现，不新开国家战争线。

## 2. 承诺点与流程

```text
开场／祠堂：知道目标、两处线索及外界查验
  → 自由阅读、查看命卷，普通探索不扣时
  → 开始首个关键取证前，显示两种行动与影响类别
  → 只读锚点成功落盘 → 默认取消的确认页
      ├─ 先保文书：住所取原件 → 校勘 → 编组情报
      │                  同时：船夫被传问，暂不亲自引渡
      └─ 先保人证：渡口取铁牌 → 质证 → 争取引渡
                         同时：住所原件被收走，不能原地拿全
  → 船夫／女囚提供必要方向 → 同一河西罪坟救援战
  → 不同战术准备＋共同救人目标
  → 战后具体后果与命卷回顾 → 下一案目标
```

不能一进地图、第一次按E、第一次拿到线索就暗中锁线。进入任一完整取证链前必须经过共同确认入口，另一地点不能绕开该入口提前拿全。若跳过取证直接申请救援出发，也须先完成同一承诺确认，不能借无情报出发绕过机会窗口。取消回到来源位置／选项，不消耗机会或改变状态。

确认文案只预告主角已知风险和影响类别，不泄露隐藏身份、正确解法、精确奖励或最终结局。例如：“你先去住所保全文书；与此同时，渡口会接受查验。可能影响：文书原件／渡口协助／战前准备。”

## 3. 两路的过程和真实区别

| 项目 | 先保文书 | 先保人证 |
|---|---|---|
| 主动行为 | 取预盖空白亡籍，与首条索引校勘 | 查新近铁牌，向船夫出示，追问其隐瞒 |
| 需要判断 | 父亲批注如何定位河西罪坟；县印意味着什么 | “三个月没渡河”与当日验痕为何冲突 |
| 完整机会 | 保全原件及编组注记，得到可核验情报 | 获得可信证言和船夫当场引渡承诺 |
| 首战可见收益 | 第一回合敌方意图可见 | 更近的入口／我方部署 |
| 外界反馈 | 船夫遭传问，仍能给最低方向，不再亲自领路 | 住所被查抄，留下查抄痕迹与来源清楚的摘记 |
| 不应发生 | 主角懂了路线就自动获得船夫协助 | 一张残抄被系统当成同样完整的官方原件 |

两路共用地图、人物、现有救援战和核心解法；差异至少包含取证操作、可见世界结果、实际战术准备与战后回顾，不能只是两句不同台词或隐藏首选flag。不将其中一路写成明显唯一正确答案。

本稿的“首战”特指当前内部版本的现有救援遭遇，是工程验证载体；不擅自替换／重排Day2已定的承岳外院首场完整战斗，也不额外新增正式第四场完整战斗。最终剧情关卡的对应关系随既定内容周再确认，不能由本周灰盒名字倒推修改全剧结构。

## 4. 补查与证据必须诚实

既定设计允许另一线在后期缩短补查，本稿不取消。完整补查窗口放在救援之后或后续终局准备，不能在同一首战前把机会成本全部补回。

- `EV_BLANK_DEATH_01`继续表示真正的预盖空白亡籍，包含原有批注／背面内容。副本或摘记使用独立ID（拟`EV_HOME_EXTRACT_01`），描述它实际保存和缺失的部分；本分支副本最多新增一项，不代表全周新增记录总量。
- 被查抄原件转入官府控制，不等于凭空消失或自动焚毁。后续如取得官方记录或等价证据，再按真实来源判断法理效力；本周不擅自写死最终裁定条件。
- “知道渡河路线”与“船夫愿亲自引渡”拆开。现有`FACT_FERRY_ROUTE`承载了知识与部署两层含义，新增流程应以独立协助事件决定部署；旧事实不能被删掉装作主角失忆。
- 同样证据能证明同样事实。不能仅因选了另一线，拒绝显然成立的校勘或把真证言变假；缺失战术收益必须来自真的信息／协助差异。
- 补查有主线价值，但不能重发首战奖励、重复收取时段或恢复已错过的当场承诺。
- 两种主解与隐藏解仍是切片要求。若新原件归属会意外让任一后续路线永久不可达，Day50必须给出等价且有代价的后续取证方案共同确认，而不是默默删掉该结局。

未完成可选质证时，女囚的记忆／必要线索仍提供河西方向，玩家能无额外情报进入救援战；此处指已确认优先路线但没有取得完整战术优势，仍需记录该次机会已消耗。不能在战后重新选择已过去的窗口或补发另一套首战收益；不要求刷关系、帮忙或猜遍证物才允许前进。

## 5. 时间与世界事件契约（待确认）

正式八剧情段仍为：第一日黎明／下午／夜间；第二日白日／傍晚／夜间；第三日黎明／正午。第七周`time_state.day/slot`是每日8技术槽，不能把旧`day=2,slot=3`直接解释成某正式剧情阶段。

建议引入有稳定ID、明确所属状态容器的剧情阶段与分支事件，不新增未经GameState／存档验证允许的散乱顶层字段。具体存储接口在Day50冻结；初步语义：

1. 已有技术钟继续服务日程原型；正式剧情阶段由主线关键行动控制，二者不互相猜算。
2. 本周只接首个机会窗口。确认“先保文书／人证”记录行动与一次机会事件，不在普通行走、交谈、读材料、失败重试时重复推进。
3. H等候／帮忙不得偷触发不可逆查抄或封城。若继续保留技术钟，界面须清楚区分“日程原型时辰”和“案件阶段”，不显示互相矛盾的清籍截止倒计时。
4. 世界处理顺序固定：已到达剧情段的公共事件 → 本次任务事件 → 人物响应 → 位置／话题／任务提示投影 → 自动保存与可见反馈。
5. 未制作的其余阶段内容、六核心NPC主动事件、完整封城／迁坟不标完成；`M08`重排须你确认，上位规格在此之前保留。

不做实时倒计时，也不以反复等候制造三十分钟流程。

## 6. 状态、确认与存档边界

建议采用现有域规则→Session→表现层架构，不再造一套任务引擎。规则只计算候选，Session持有确认权限，UI只提交意图。

- 概念状态：`uncommitted → home或dock → settled`；旧档已双收益为明确兼容态，不作为新路线可达态。稳定任务／事件ID在Day50冻结，不用匿名布尔组合代替收据。
- 候选含选择、相关状态版本、影响类别和准确效果摘要；确认时重新校验。过期token、内容reload、重复按键不得接受旧结果。
- 只读锚点保存进入本次选择前的完整状态，按路线与节点身份隔离、只创建一次、不被自动轮转覆盖；章节未结束不清理。`auto_01`并不等于只读锚点。
- 锚点失败：清楚报错，不改变运行时状态、不发放token或接受选择；玩家仍可取消、退出或修复存储后重试。
- 确认成功：一次性发布候选状态与不可变事件，再保存必要结果；后续保存失败须显示“尚未保存”、保留运行时已确认结果并允许重试保存，不重新执行事件或回退一半字段。
- 战斗失败重试使用同一战前快照，不重新查抄、扣时、选线或发奖励。退出恢复既定出发前状态，不撤销已完成的前置分支。
- 所有相关字段一起保存：任务／选择／事实、证据认知、原件持有、关系、时间／阶段、武学、玩家与NPC投影来源；恢复不能只读一个路线flag。
- 当前`StoryEncounterRules.validate_persistent_state()`要求`QUEST_TRACE_LEDGER=available`。若战后推进该任务，必须新增合法后继状态与收据契约，兼容旧胜利档，不能删除整段验证放行。

普通自动槽轮转、关键任务／时段自动保存仅在明确注册的本周事件触发，防止一次对白或重复load刷档。未来完整八阶段接入仍须测试；保护本次选择不等于M10／M11全部完成。本周不开放立即撤销、章节重勘或旧义庄最终裁定回溯。

旧档策略：未进入新承诺点的旧档是否可加入新流程，按实际已有证据／任务判断，不凭缺字段推断“什么都没发生”；已经拿到双收益／已经胜利的旧档保留原事实、原件、奖励与后续可达性，不没收。兼容态不计新分支验收，迁移不得悄悄改写玩家槽。

## 7. 约30分钟的内容预算与测试

| 环节 | 初始预算 | 观察点 |
|---|---:|---|
| 开场、祠堂和动机 | 4～6分钟 | 玩家能说出为什么留下、去哪、命卷用途 |
| 一路取证与选择 | 7～10分钟 | 查／问／证／校至少产生实际判断，不穷举所有按钮 |
| 世界反馈与战前准备 | 3～4分钟 | 知道错过什么类型机会、为何获得当前战术条件 |
| 救援战 | 5～8分钟 | 能看懂目标／技能条件，情报改变至少一个决策 |
| 战后查证／回顾 | 3～5分钟 | 看清救人的结果、证据用途和下一个未解问题 |

合计22～33分钟是待验证的制作预算，不是现有实测；整体中心目标约30分钟。不能把每个上限同时当承诺，更不能把阅读慢当内容量。Day50实测若与预算差距明显，先调整有效节点和估时。

战后可细化既定“尸牌＋残页→亡籍无尸”的校勘与人物回应，不新增独立案件。这两项虽已在Day2设计，不是当前已实现的取证内容；若本周接入，Day50须另列两项记录、文本／交互／规则／本地化／测试工时，并与上述副本一起核对全切片12～16条记录的总预算。不能以“已有设计”视为免费。若超出本周容量，保留时长门未达并重新排期，不拿短流程改名30分钟。

必须分别测试纸／人两路、无额外情报、错误质证、取消／重复确认、写盘失败、两路独立冷重启、旧双收益档与胜利档。真人首次测试不展示本稿解法，反馈入口为[第八周试玩表](./week8_playtest.md)。
