| 诉求 | 首轮行为（不可用项已被第二轮取代） |

| 分类 | 招式名旁标出攻击、攻击／减益、防御、防御／援护、恢复／防御、机动／防御；保留原菜单顺序，不增加一级分类菜单 |
| 看效果 | 选中即显示范围、伤害、附加状态数值、内力消耗和冷却；普攻的回内力效果也可见 |
| 大概多少伤害 | 有合法攻击目标时，列出按各目标计算的实扣血范围；无合法目标时明确标记“参考”，条件为护体0、无状态，包含距离加成 |
| 具体目标预览 | 光标选中敌人后显示该次攻击的伤害和实扣，计算护体、破势、守势、援护和剩余气血上限；代受时显示实际承受者 |

| 多人效果 | 援护显示自身及相邻范围，并标记实际受到效果的友军；攻击被援护时橙框标出真正受击者 |
| 不可用技能 | 内力不足、冷却、绝技条件未满足时仍可看灰色范围，但没有合法目标亮框，也不能执行 |
| 返回位置 | Esc从确认退回原目标格，再退回刚才的技能行；重新进入同一技能保留该技能上次目标格。不同技能分别记忆；角色切换、移动确认、重试后清除旧记忆 |
| 临时页面 | 规则、重试、战前目标和单位查看页面取消后恢复原界面及选项；不消耗行动、资源或修改探索存档 |

## 第二轮反馈：禁选与敌方移动范围（历史记录）

用户原话：

> 1.不可执行的命令应该不可选择；2.移动时候，可以高亮敌方可移动的范围；此外画面表现和数值之后再进行细化。

已实现：

- 不可执行的指令保留在原位置，置灰并带“×”和原因；↑↓／W/S跳过它们，E／Enter不能进入或执行，不再通过选中锁定技能查看灰色范围。
- 禁选条件包括移动已用、没有其他可走格、内力不足、冷却中、绝技条件未满足或本战已用，以及当前没有合法目标。判断复用真实预览规则；移动、行动切换、重试后刷新可用性。守势和吐纳仍可在无敌人可攻击时使用，不形成死菜单。
- 可用招式保留首轮的分类、效果、伤害和范围预览及返回记忆。无合法目标的攻击现在禁选；首轮“无目标时显示参考伤害”的只读计算接口保留，但不再作为可选指令入口。
- 选移动目的地及确认移动时，自动叠加所有存活敌人的可移动范围。青色为我方可走，紫框为敌方可走；仅敌方可走处填紫色，重叠格保留青色和紫框。取消／离开移动模式后清除叠加。
- 敌方范围采用当前真实站位、障碍／单位阻挡和牵制后的移动额度；不是攻击覆盖范围，也不是预告AI下一步落点。光标尚未确认时，不把角色当作已经移动。它展示各敌人从当前站位出发的范围，不模拟多个敌人依次移开后的未来路线。
- 按用户决定，画面表现、逐招动画、正式美术和数值平衡留待后续细化；本轮只增加操作必需的禁选样式与范围提示，没有改技能数据、伤害或AI策略。

## 第三轮反馈：可以查看，不能施放（当前行为）

用户原话：

> 有个问题，无法选择的话，无法知道怎么才能选择，比如无法区分绝技的触发条件。

将“光标停留查看”和“确认执行指令”分开：

- ↑↓／W/S可停在任何一行，包括置灰项。当前查看行有亮色箭头，禁用文字仍为灰色。每次角色／移动确认切换时初始焦点优先落在可执行项，此后浏览不跳过灰色项。
- 不可执行项按E／Enter只保留该行和说明，不进入选目标／移动模式，不消耗资源或行动。可用项的选格、二次确认和返回记忆不变。
- 绝技卡始终显示具体触发条件、进度和次数：主角“本战实际受敌伤 0/6”，同伴“本战本人击倒 0/1”；未用时标“每战1次”，用过则标“已用1/1”。这些来自当前遭遇数据和真实战斗计数，不是另写一套解锁规则。
- 底部解释尚缺多少；例如主角显示“本战还需实际承受敌方伤害3点”，同伴强调必须由本人击倒。满足条件但没目标，与条件不足和本战已用分别提示；即使同时内力不足，卡片仍显示触发条件。
- 其他置灰项也解释恢复办法：内力当前值／需要值以及普攻／吐纳恢复；冷却的当前轮／恢复轮；无目标时提示接近敌人或避开射线遮挡；移动已用提示完成行动后下回合恢复。
- 灰色技能仍可查看物理范围及注明假设的参考伤害，但不能据此施放；真正可选目标和实际伤害继续由真实预览规则计算。第二轮敌方移动范围保留。画面表现和数值细化仍暂缓，没有修改触发阈值、技能数值或AI策略。
