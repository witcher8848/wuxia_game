# 第八周内容脚本与计时预算

更新：2026-10-19。对应[每日排期](../武侠RPG_第八周每日任务.md)与[分支设计](./week8_branch_design.md)。本文件记录已接入源码的内容、规则接口与待验体验，不是三十分钟实测、五人反馈或整周验收。M08按你的确认分阶段接入：本周首窗口与相关世界事件，其余三日八阶段／六核心NPC事件保留第13～16周随剧情落地。

## 1. 本轮写作边界

继续使用三张探索灰盒、父亲／女囚／船夫与现有救援遭遇。不新增正式第四场完整战斗，不把内部救援载体改写为承岳外院首战，不开放旧义庄地图、终局裁定、恋爱线或身世真相。

两个选择都服务同一眼前目标：找到经手旧账的活证人，保住能复核的材料。错过的是完整机会，不是另一份真相；没有情报也能由女囚带路救人，不能被调查穷举或关系刷取卡住。

## 2. 两路实际内容

| 环节 | 先保文书 | 先保人证 |
|---|---|---|
| 共同承诺 | 先展示影响类别并保护选择前状态；选择本身不授予证据或战斗奖励 | 同左 |
| 取证 | 在住所取得真正的预盖空白亡籍；与索引校勘 | 记录船夫的“三月未渡”说法；检查铁牌；出示时间与人物归属矛盾 |
| 可选判断 | 县印先于姓名说明流程疑点，但不能直接证明父亲无罪 | 今日验痕只说明有人渡河；铜钉补法才把物件与老妇关联 |
| 对侧代价 | 船夫被传问；仍可给方向，不能亲自领渡 | 住所被查抄；原件转入官方控制，不是凭空毁掉 |
| 首战准备 | 只有出发前完成原文书校勘才有首轮意图情报 | 只有出发前成功质证并争取到协助才有更近部署 |
| 战后补查 | 需在码头靠近船夫实际补问、核对同一铁牌与旧证言；不能远程领取或让已经结束的战斗重发部署 | 结尾只给回住所指引；须实际回住所靠近文书点才能取得独立抄记。没有县印、编组图或完整方位简记，不冒充原件 |

战后回顾使用“是否实际完成前置”措辞，不因选了某路就声称已经取得对应奖励。既有事实不因错过机会而消失，补查也不能恢复过去的当场协助。

## 3. 共通收束：救人后能查明什么

1. 女囚打开老妇撤离时托付的布包，实际登记尸牌与私人埋尸簿残页。
2. 玩家可分别翻看正反刻痕、正文与页边记号，再进行一次二项校勘。索引和铁牌仍可作为可解释的错误选项，不靠猜遍全部记录。
3. 尸牌“第七列三号／女子病亡”与残页“无骨／旧牌换字，不添新骨”对应，核实至少一笔死亡登记没有对应的新入葬。
4. 可追问推论边界：不能断言名册全假、所有人仍活着或父亲已经无罪。真死、假死和换名仍可能混存。
5. 记录本段结论，下一案为去旧义庄找老妇与真簿，核对女囚父亲遗骨及父亲改籍缘由。这里是内部止点，不宣称已经完成后续案或最终裁定。

尸牌和残页的“来源”字段使用现有`CHAR_PRISONER`，表示实际转交者；物品正文明确其原来由老妇保存、刻制者并非女囚。未为一件物品新增一个holder或正式人物资产。

## 4. 数据与接线契约

新节点按`D_W8_`命名；关键节点为`D_W8_HOME_SEIZED`、`D_W8_BOATMAN_QUESTIONED`、`D_W8_AFTER_HOME/DOCK`、`D_W8_GRAVES_FOUND`、`D_W8_GRAVES_MATCHED`及`D_W8_END`。静态图将两条战后节点挂入新流程入口保证配置可达；运行时ContentDB按真实收据选择对应节点，而不是让永远排在前面的默认文书节点吞掉码头路线。

`@graves_compare`是本周新增活动，复用二项校勘面板。对话节点仍为2～4选项、只调用严格登记步骤，不含脚本、任意属性路径或UI直接结果。

旧文案保留给兼容流程。新流程应使用`W8_INTRO_ROUTE`、`W8_D_JOURNEY_TEXT`、`W8_BATTLE_NO_HOME/DOCK`替代“随时能把另一边补齐”的旧提示；战后补问使用`W8_BOATMAN_ADMITS_LATE`，不能承诺已结束救援重新部署。目标键为`W8_OBJECTIVE_CHOOSE/HOME/DOCK/AFTERMATH/COMPARE/REVIEW/END`。

## 5. 记录总预算

本次调查注册从4条增至7条：原有索引／空白亡籍／铁牌／船夫证言，加一项抄记与两项既定墓证。副本新增一项，不把两项墓证漏算；没有另增“同一铁牌的新ID”或伪造同ID原件。

全切片12～16条记录预算仍包含后续武证、官籍、师承与真簿等。当前7条不意味着剩余所有设计可免费添加；后续数据应继续逐条盘点。不把这里的7条当作全切片内容完成。

## 6. 时长预算与验证方式

下面是制作假设，不是实际试玩结果。未用字数、自动按键耗时、两路相加或代理行为证明30分钟。

| 单条自然流程 | 待验证预算 | 需要产生的行为 |
|---|---:|---|
| 序章与祠堂 | 4～6min | 理解父亲遇害、老妇价值和命卷用途；做第一次主动决定 |
| 一路取证与承诺 | 5～8min | 阅读2～3项关键材料，完成一次有依据的出示或校勘；不要求读完可选解释 |
| 世界代价与出发整备 | 2～4min | 看懂另一处发生了什么；选择是否带现有情报出发并检查武学 |
| 救援战 | 5～8min | 根据目标、技能范围与已有准备完成掩护；不靠重复失败计算 |
| 战后墓证与回顾 | 4～6min | 翻看两项墓证，完成校勘，区分事实与猜测，知道下一案为何要去旧义庄 |

预算总和20～32min，中心目标仍约30min。这比计划中的22～33min更保守；新增墓证提供实质判断，但不能据此保证补足原约10min流程的差距。必须在候选版本中按阶段记录首次自然单路时长。若自然通关仍显著不足20min，不延迟文本、降速、刷帮忙或强迫穷举补时，应保留时长门未达并另估实质内容迭代。

真人记录由用户转发候选并收集，填写[试玩表](./week8_playtest.md)。测试者第一次不展示本文解法；代理与自动输入只证明通行、持久化及画面，不计五名真人反馈。

## 7. 内容验收清单

- 两路从同一开场有可理解的选择，预告类型不泄露隐藏身份或最终正确路线。
- 没有额外情报仍能出发；错误质证、错误校勘、取消和重开不改事实或消耗窗口。
- 战前不能无成本拿齐双方完整准备；战后补查来源真实、不冒充原件、不恢复过去收益。
- 人证路线在战后推进追账任务时，原救援持久化验证接受合法后继但仍验证既有胜利收据。
- 中文与英文关键正文、按钮、事实边界一致；长文可滚动，不让闲谈先占正文。
- 命卷清楚显示已知事实、原件归属、取舍记录与当前目标，未完成的下案和最终结局不签完成。
- 对话／调查旧流程仍有回归证据，新流程额外验证尸牌／残页顺序、错误组合、重复结算及两路冷重启。
