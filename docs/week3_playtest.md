## 启动

- macOS工作区：双击根目录`Battle.command`。`Run.command`仍是第二周探索，不会进入战斗。
- 独立Windows评审候选：让`ProjectWumingBattle.exe`与同名`.pck`保持相邻，双击EXE。包内`build_info.json`与`SHA256SUMS.txt`标识该候选；Windows真机仍待实测，不能凭Mac测试当作已通过。
- 第一次从源码恢复需要按README安装固定版Godot。当前仅要求键盘，保留原输入映射；没有宣称战斗界面实体手柄可用。
- 本原型不读写探索进度，无战斗存档、永久奖励、剧情关系或普通装备／用药。

## 操作

| 操作 | 按键／行为 |
|---|---|
| 选择指令 | ↑↓或W/S |
| 移动／攻击选格 | 方向键或WASD |
| 确认 | E／Enter；先选目标，再确认预览，最后执行 |
| 返回 | Esc；在主菜单按Esc会询问是否退出 |
| 看敌人 | F进入查看模式，选到敌人可看行为类型与移动范围；Esc返回 |
| 看状态规则 | F1 |
| 切换评审目标 | F2，选择击退或撤离；会开始新一局 |
| 原配置重试 | R后E确认；Esc可保留当前局 |

每回合可先移动一次、再行动一次；移动确认后不能反复补走。普攻回内力1，吐纳回2并守势；武学和绝技都占行动。掠水步忽略单位阻挡但不能穿墙。主角绝技需累计实际受敌伤6，同伴需击倒1名敌人，每人每战一次，均为可调整原型数值；不需要绝技也能取胜。

冷却1表示使用后的下一整轮不可用，再下一轮恢复。援护须受击时仍与施术者相邻，仅首击生效，不连锁，轮结束到期；流血在行动后扣血。绿色边框是撤离格；该模式只有主角抵达才赢，清场本身不结束战斗。
