# 第六周反馈版：短试玩表

2026-10-15。本轮为0.6.1反馈修订；先不要用旧0.6.0包判断新规则。Mac启动器需要本机已有Godot，Windows／实体手柄未验。修改依据、源码证据与规则边界见[反馈处理记录](./week6_feedback_followup.md)。

## 入口与操作

源码`CombatV1.command`进入演武；正常探索按M整备，E应用，F5才保存。演武←→选清场／护证，M换招，E开战。F查看、V状态期限、T红纹现站位射程、F1规则；红纹忽略内力／冷却，不是下一步锁定攻击，紫色仍是敌方移动。

R确认原配置重试；F2确认放弃本局返回整备。攻击与移动仍先预览、再次确认；Esc取消不花内力，返回保留选项／目标。横截选相邻方向格，可为空或有友军，前排至少一敌且不伤友军。

## 建议用两套配置各试一次

破阵：绊腕／直势／横截；护证：直势／护剑／横截。身法与内功先相同。清场关注破势接击、耗气与同伴承伤；护证关注保持邻接、代受与主角承伤。并非两套唯一路线，不承诺其中一套在所有情况下最佳。随后可卸内功感受3上限／普攻回0／吐纳回1；有内功为5／1／2。
