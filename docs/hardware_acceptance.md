## 系统备份与卖点理解

`tmutil destinationinfo` 返回 `No destinations configured`。需要选择备份磁盘或既有备份方案，启用每日备份后恢复一个源文件到独立目录，比对哈希并记录结果。本机 Git 提交／bundle 可以用于版本恢复和转移，但同一磁盘上的副本不满足独立备份要求。
